# 🏥 Hospital Emergency Room Dashboard – Excel

## 📊 Project Overview

The **Hospital Emergency Room Dashboard** is an interactive Excel dashboard created to analyze and monitor Emergency Room (ER) patient data.

The dashboard provides a clear overview of patient volume, waiting time, satisfaction score, admission status, gender distribution, age groups, attendance time, and department referrals.

---

## 🎯 Objectives

- Analyze the number of ER patients
- Monitor average patient waiting time
- Track patient satisfaction scores
- Compare admitted and non-admitted patients
- Analyze patients by gender and age group
- Monitor patients attended within the expected time
- Analyze department referral patterns
- Compare ER performance by month and year

---

## 🛠️ Tools Used

- Microsoft Excel

## 📌 Key KPIs

The dashboard includes the following key performance indicators:

- **Total Number of Patients**
- **Average Wait Time (Minutes)**
- **Patient Satisfaction Score**
- **Admission Status**
- **Patients Attended Within Time**

---

## 📈 Dashboard Analysis

### 👥 Patient Analysis
The dashboard displays the total number of patients and provides demographic analysis based on:

- Gender
- Age Group
- Admission Status

### ⏱️ Waiting Time Analysis
The dashboard tracks the **average waiting time** and compares patients who were attended within the expected time with those who experienced delays.

### ⭐ Patient Satisfaction
The dashboard monitors the **patient satisfaction score** to provide an overview of the patient experience.

### 🏥 Department Referral Analysis
Patients are analyzed based on department referrals, including:

- General Practice
- Orthopedics
- Physiotherapy
- Gastroenterology
- Cardiology
- Neurology
- Renal
- No Department Referral

### 📊 Age Group Analysis

Patients are categorized into different age groups:

- 0–4
- 5–14
- 15–29
- 30–44
- 45–59
- 60–69
- 70–79
